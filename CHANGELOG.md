# Changelog

Every change bumps the patch number by 0.0.1, and each version has an annotated git tag.

## v1.0.1

- Build version in the footer and README is now current.

## v1.0

- Browse Chat JSONs button opens the chat folder in a new tab.
- Geist and Source Code Pro are embedded in the page.
- Auto-scroll is a button that switches on and off.
- The seek hint moves into the empty chat box.
- Search box renamed from "Filter messages" to "Search".
- Top-bar buttons use the lit style with a hover glow.
- Status text sits next to the title.
- Fullscreen Chat puts the video and chat together, with no outer padding or rounded frames.
- Profile pictures and emoji appear in the chat.
- Messages wrap at spaces, and the username sits above the message.

## v0.1.0

- First working player: local video and live_chat.json, synced chat, click to seek.
